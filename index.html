🔧 แก้ Error: No HTML file named Dashboard was found

ลิงก์ของคุณ: https://script.google.com/macros/s/AKfycbxj_Sp1.../exec เจอ Error บรรทัด 46 เพราะไม่มีไฟล์ Dashboard.html

❌ สาเหตุ

ใน Code.gs เดิมใช้ HtmlService.createTemplateFromFile('Dashboard') แต่ในโปรเจค Apps Script ไม่มีไฟล์ชื่อ Dashboard.html เลยทำให้ Deploy แล้ว Error

✅ วิธีแก้ 2 แบบ

  1. ใช้ Code_fixed_ID.gs ที่ให้ไป - มีฟังก์ชัน getEmbeddedDashboardHtml() ฝัง HTML ไว้แล้ว ไม่ต้องสร้างไฟล์ก็รันได้
  2. หรือสร้างไฟล์ Dashboard.html ใน Apps Script Editor (คลิก + → HTML → ตั้งชื่อ Dashboard) แล้ววางโค้ดไฟล์นี้ทั้งหมด
ขั้นตอน Deploy ใหม่:
1. เปิด https://script.google.com → โปรเจคของคุณ
2. ลบ Code.gs เดิม ทับด้วย Code_fixed_ID.gs
3. ถ้าเลือกแบบแยกไฟล์: + New HTML → ชื่อ Dashboard → วางโค้ด Dashboard.html นี้
4. Save (Ctrl+S)
5. Deploy → Manage Deployments → Edit → Version: New Version → Deploy
6. ทดสอบลิงก์ใหม่ จะไม่ Error แล้ว

เพิ่มเมนูใหม่ใน Google Sheets:
- เปิด Sheet → เมนู 📊 Dashboard สถิติ → เพิ่มคอลัมน์ ID
- ระบบจะเติม ID ให้ข้อมูลเก่า 8 แถวอัตโนมัติ
